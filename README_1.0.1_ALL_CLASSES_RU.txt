AlterEgo Desktop 1.0.1 — исправление цветов всех 13 классов.
Программа читает ID, file/token или название класса каждого персонажа из AlterEgo.lua.
Поддерживаются числовые ID, английские и русские имена. Неизвестный класс — нейтральный цвет.
Применяется к таблице и Enchants & Gems Check. Сохранены изменения иконки из предыдущего архива.
Сборка: BUILD_WINDOWS.bat. Проверены синтаксис и тесты определения цветов, но не запуск Windows GUI.
Не публикуйте v1.0.1 до проверки на вашем компьютере.
