AlterEgo Desktop 1.0.1 — исправления классов и иконки.

Класс персонажа берётся из вложенного info.class.id/file (формат AlterEgo.lua). Цвет шамана #0070DD, охотника #AAD372. Иконка app.ico встраивается в EXE и назначается Qt-приложению/главному окну, включая панель задач.

Собрать через BUILD_WINDOWS.bat. Проверить на Windows, затем опубликовать GitHub Release v1.0.1 (не pre-release), прикрепив dist\AlterEgo Desktop.exe. Пользователи версии 1.0.0 смогут нажать Update.

Синтаксис и извлечение class из примера AlterEgo.lua проверены. Windows GUI не тестировался.
