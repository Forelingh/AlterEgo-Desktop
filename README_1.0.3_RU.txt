AlterEgo Desktop 1.0.3 — обновление таблицы и Manage Characters

1. Nebulous Voidcore:
   В подсказке Season Maximum используется наибольшее значение maxQuantity /
   maxWeeklyQuantity среди всех загруженных персонажей. Это значение общее
   для всех персонажей и не требует входа в каждого персонажа в WoW.
   Собственные количества Voidcore у персонажей не изменяются.

2. Прокрутка таблицы:
   Колесо мыши над таблицей прокручивает список персонажей по горизонтали.
   Вертикальная полоса прокрутки скрыта; нижняя горизонтальная полоса остаётся.

3. Manage Characters:
   Колесо над селектором номера персонажа больше не меняет номер.
   Номер выбирается только раскрытием списка и щелчком мыши.

Версия: 1.0.3
Сборка: запустить BUILD_WINDOWS.bat.
Проверен синтаксис Python; поведение интерфейса требуется проверить на Windows.
