AlterEgo Desktop 1.0.4 — исправление Season Maximum Voidcore

Причина: maxQuantity может содержать общий лимит валюты (например 30), а maxWeeklyQuantity — сезонный максимум (например 7).

Исправление: программа теперь в первую очередь использует maxWeeklyQuantity. maxQuantity используется только как запасной вариант, если weekly-поле отсутствует.
Глобальный Season Maximum по-прежнему выбирается среди загруженных персонажей.
Остальные функции версии 1.0.3 сохранены.

Сборка: запустить BUILD_WINDOWS.bat.
Синтаксис Python проверен; перед публикацией проверить на данных игрока, у которого ранее показывалось 30 вместо 7.
