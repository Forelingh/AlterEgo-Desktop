AlterEgo Desktop 1.0.5 — исправление Season Maximum Voidcore

По предоставленному AlterEgo.lua видно, что у Nebulous Voidcore поле maxWeeklyQuantity равно 0, а актуальный Season Maximum записан в maxQuantity (например, 7). В предыдущей версии ноль ошибочно принимался за найденный лимит, из-за чего общий максимум становился 0 и отображалось No limit.

Исправление:
- использовать положительный maxWeeklyQuantity, если он присутствует;
- если maxWeeklyQuantity отсутствует или равен 0, использовать положительный maxQuantity;
- игнорировать нулевые значения при поиске общего максимума;
- сохранить общий максимум среди всех загруженных персонажей.

Версия 1.0.5. Сборка через BUILD_WINDOWS.bat.
Синтаксис проверен. Перед публикацией проверить на своём профиле и профиле товарища.
