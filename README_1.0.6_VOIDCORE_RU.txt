AlterEgo Desktop 1.0.6 — Season Maximum Voidcore

Изменения:
1. Общий Season Maximum рассчитывается только по персонажам, которые отмечены
   галочками в Manage Characters (ключи из settings.json -> hidden исключаются).
2. Учитываются только записи Nebulous Voidcore с ID 3418.
3. Используется maxQuantity — в предоставленных файлах AlterEgo именно там
   хранится сезонный максимум; maxWeeklyQuantity равен 0.
4. Исключаются источники AlterEgo.lua, отстающие более чем на 7 суток от самого
   свежего найденного файла. Это предотвращает влияние старого файла с лимитом 30.
5. Если нет ни одного подходящего отмеченного персонажа с актуальным значением,
   максимум не подменяется устаревшими данными.

Проверить перед публикацией:
- у пользователя с проблемой 30 должно показываться 7;
- снятие галочки с персонажа с максимальным значением должно исключать его из расчёта;
- повторная установка галочки должна возвращать его в расчёт;
- проверить пользователя, у которого несколько аккаунтов.

Сборка: BUILD_WINDOWS.bat.
Версия 1.0.6. Синтаксис Python проверен; поведение проверить в Windows.
